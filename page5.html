Technologies Used

  • HTML: To structure the website pages.
  • CSS: To style the pages and make them responsive.
  • JavaScript: To handle user interactions and connect the pages to Supabase.
  • Supabase: To manage authentication, the PostgreSQL database, and cat photo storage.

Development and Collaboration Tools

  • Visual Studio Code: To write and edit code.
  • GitHub: To track code changes and collaborate.
  • Google Stitch: To explore interface design ideas.
  • Microsoft Teams: To communicate and coordinate tasks.
