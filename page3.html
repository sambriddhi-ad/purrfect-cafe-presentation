User Stories

As a customer:

  • create an account and log in so that I can manage my bookings.
  • view cat profiles so that I can learn about the cats before visiting.
  • browse the food and drink menu so that I can see what the cafe offers.
  • book an available session so that I can spend quality time with the cats.
  • update or cancel my booking so that I can adjust my visit when my plans change.

As an administrator:

  • manage sessions so that I can control visiting times and capacity.
  • view and manage bookings so that I can organise customer visits.
